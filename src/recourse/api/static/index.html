Don't turn an exception into a human job. A HUMAN JOB.

An autonomous worker shouldn't lose an entire job because one transaction failed. KEEPR isolates the failure, recovers what it safely can, verifies the outcome, and keeps the rest of the job moving without expanding the worker's authority.

Each failure class gets a bounded, deterministic recovery policy. The other 49 invoices don't become a human job.

503 Service Failure

Malformed Response

401 Unauthorized
Escalated Immediately
Authentication failures are never retried. Human judgment required — escalated with full evidence.
Partial Result
Rolled Back Safely
Incomplete work undone via compensating actions. Item restored to PENDING. Job resumes.
False Completion

Agent claims DONE. Ledger disagrees. KEEPR rejects, rolls back, freezes. The other 49 continue.
Authority Widening

Out-of-scope request intercepted before any adapter is touched. Recovery cannot expand power.
Conflicting Sources
Frozen, Halted
